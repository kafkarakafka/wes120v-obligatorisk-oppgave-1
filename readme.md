# Mitt WES120V-prosjekt

## Beskrivelse

Dette er et nettsideprosjekt utviklet som en del av den obligatoriske oppgaven i WES120V.

## Forutsetninger

For å kjøre dette prosjektet må du ha Node.js og pnpm installert på maskinen din.

## Installasjon og oppstart

1. Installer avhengigheter: pnpm install
2. Start utviklingsserveren: pnpm dev
3. Åpne nettsiden på adressen som Vite viser i terminalen (for eksempel http://localhost:5173)
